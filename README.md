# Terra Graph

Website for Terra Graph, an AI-powered digital marketing agency.

A static single-page site: `index.html` with images in `img/`. There's no build step.

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```

## Deploy

Works as-is on GitHub Pages (Settings → Pages → deploy from the `main` branch, root folder), Netlify or Vercel.
